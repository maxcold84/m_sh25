블로그 게시물 레이아웃 개선

미니멀리스트 블로그 게시물 레이아웃 개선 블로그 게시물 레이아웃이 더 현대적이고 휴고에 최적화되었으며 모바일 친화적으로 업데이트되었습니다.

주요 변경 사항

  1. 인터랙티브 요소 읽기 진행 막대: 스크롤할 때 채워지는 화면 상단의 미묘한 막대. 목차(TOC): 섹션 간 쉽게 탐색할 수 있도록 데스크톱에 끈적끈적한 상태를 유지하는 사이드바 TOC입니다. 포스트 내비게이션: 아래쪽의 간단한 ‘이전 게시물’ 및 ‘다음 게시물’ 링크는 추가 읽기를 권장합니다.
  2. 현대 형식 지정 읽기 시간: 휴고가 자동으로 계산하여 메타 섹션에 표시됩니다. 타이포그래피 개선: 가독성을 높이기 위해 선 높이와 간격을 최적화했습니다. 모바일 우선 디자인: 레이아웃은 작은 화면에 맞게 매끄럽게 조정됩니다(TOC는 모바일에 숨겨져 있어 미니멀하게 유지할 수 있습니다). 수정된 파일
싱글.html
더 나은 구조와 기능을 위해 템플릿을 다시 작성했습니다.
style.scss
새로운 구성 요소에 미니멀리스트 스타일을 추가했습니다. 검증 결과 .ReadingTime과 .TableOfContents가 올바르게 렌더링되는 것을 확인했습니다. 스크롤 진행 막대 기능이 의도대로 작동하는지 확인했습니다. 다양한 뷰포트 크기에서 응답성을 확인했습니다.
