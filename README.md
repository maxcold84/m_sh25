# Main_Shop 25
25년 12월 완성된 이커머스페이지를 패킹.

# 프로젝트 개요
이 프로젝트는 한국어 문서가 포함된 Hugo 기반의 정적 웹사이트입니다. 사용자는 이 웹사이트를 통해 다양한 정보를 쉽게 얻을 수 있습니다.

# 디렉토리 구조
```
/m_sh25
├── archetypes  # 아키타입
├── content     # 콘텐츠
├── layouts     # 레이아웃 템플릿
├── static      # 정적 파일 (CSS, JS, 이미지 등)
└── config.toml # 설정 파일
```

# 설치 방법
1. **Hugo 설치**: [Hugo 설치 방법](https://gohugo.io/getting-started/installing/)을 참조하세요.
2. **프로젝트 클론**: `git clone https://github.com/maxcold84/m_sh25.git` 명령어로 프로젝트를 클론하세요.
3. **의존성 설치**: 필요한 의존성을 설치합니다.
4. **서버 실행**: `hugo server` 명령어로 로컬 서버를 실행하세요.

# 사용 방법
- 웹사이트를 로컬에서 실행하여 콘텐츠를 확인합니다.
- 콘텐츠를 추가하거나 수정하려면 `content` 디렉토리 내의 파일을 편집하시면 됩니다.
