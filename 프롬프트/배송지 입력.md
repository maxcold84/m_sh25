너는 프론트엔드(HTML·TailwindCSS·Vanilla JS)와 PocketBase REST/JS SDK를 능숙히 다루는 시니어 개발자야.
다음 조건을 만족하는 “Checkout / 배송지 입력” 단일 페이지 코드(한 파일)와 간단한 사용 설명서를 작성해 줘.

기술 스택
① 정적 사이트 제너레이터: Hugo

layouts/checkout/single.html 로 저장할 수 있는 형태
{{ partial }} 또는 {{ resources.Get }} 등 Hugo 문법 사용 가능
② 백엔드: PocketBase
collection cart, collection products, collection orders 가 이미 존재
cart 레코드는 { id, user_id, product_id, qty }
③ 주소 자동완성: Naver Map Geocoding & Search API
Endpoint: GET https://naveropenapi.apigw.ntruss.com/map-geocode/v2/geocode?query=…
HTTP 헤더
X-NCP-APIGW-API-KEY-ID: {{ getenv "NAVER_ID" }}
X-NCP-APIGW-API-KEY: {{ getenv "NAVER_SECRET" }}
사용자는 ‘주소 1줄 입력’ input에 타이핑할 때마다 300 ms 디바운스로 API를 호출하고,
드롭다운(최대 5개)에서 주소를 선택하면
• roadAddress, jibunAddress, x, y 값을 hidden input 에 세팅
• 선택된 주소를 요약 형태로 카드를 갱신
화면 구성(모바일 First)
헤더 : “주문/결제” 타이틀
섹션 A : 배송지 카드
- 수령인, 휴대폰(안심번호), 도로명주소, 지번, 우편번호, 상세주소 input
- “다음에도 사용할게요” 체크박스
섹션 B : 주문상품 요약 리스트
- 각 상품 썸네일 (80×80) / 상품명 / 옵션 / 수량 / 소계
- PocketBase SDK 로 현재 로그인 사용자의 cart 항목을 조회해 렌더
섹션 C : 총 주문금액 합계(원화 ,)
섹션 D : “결제하기” 고정 바텀 버튼
- 클릭 시 validate → PocketBase orders 컬렉션에 { user_id, items[], shipping_info } 추가 후 결제 모듈로 이동(dummy alert OK)

UX · UI

TailwindCSS CDN 버전 사용
실시간 입력 시 로딩 스피너, 에러 토스트 제공
자바스크립트는 모듈 스코프(IIFE) + ES6 fetch 사용
비동기 함수는 try/catch + console.error
모든 한글 텍스트는 문어체
보안

Naver API 키는 직접 하드코딩 금지. Hugo 내 .env.hugo 나 Netlify env 로 주입 → JS 빌드 시 data-attributes 로 전달
CORS 우회 필요시 백엔드 프록시(“/api/geocode”) 라고 주석만 남겨줘
